Focus

Tap the one that needs you, and its terminal comes to the front

The board used to be read-only: it told you an agent was waiting and left you to find the window yourself. Now a tap reaches back. In iTerm2, WezTerm, tmux and Warp it raises the exact pane or tab the session is in; in Terminal, Ghostty, Alacritty, VS Code and the rest it brings the app to the front, which is as far as those let anything reach. If the session has already ended, the board offers to resume it instead.

Cards say which machine they are on, so the same project running on two computers is no longer two identical cards. Focus is macOS only, and the installer above sets it up by default there — pass --no-focus to skip it. A machine without it simply shows no Focus control. Which terminals it reaches · one key press per agent.

Blocked

Know when you're the bottleneck

An agent that hits a permission prompt carries the alarm colour and can send a push notification, so a five-second approval doesn't cost you an hour.

Limits

Watch your plan, not the clock

One block per agent, up to three across: the session and weekly windows for Claude and for Codex, including the per-model caps both of them report, each with the time until it resets. Green, amber, red as a window fills.

Tokens

See where they actually went

Tap a limit block for thirty days of spend: tokens per day as bars, the plan limit drawn over them as a line, and a ranked breakdown of which projects spent it. Each card also carries its own session's running total, so two agents in one repo are two numbers rather than one shared row.

The bars and the line track each other and are not the same measure. The screen says so, because a percentage of an unknown quota and a token count do not convert.

History

Replay what happened

Tap any session — on the board or in the app — for its timeline: every status change and command, timestamped, so you can see where a long run actually went.

Yours

Open source, self-hostable

MIT licensed, and one Node process — with Postgres if you want it to survive a restart, and nothing at all if you do not. Use the hosted board or run the whole thing yourself; the guide is one page.

And on the phone in your pocket.

The iOS app shows the same board, on iPhone and iPad, with the usage charts and a timeline of everything each agent did. Try it without pairing anything — it ships with a demo board.

Running in about a minute.

One command wires up the hooks. No account, no sign-up — a board is just an unguessable URL.

01

Install the hook

Sets up Claude Code, and OpenAI Codex too when it finds it. Your existing settings are preserved, and the same command upgrades a machine later without touching your board.

curl -fsSL https://agstatus.online/install.sh | sh irm https://agstatus.online/install.ps1 | iex /plugin marketplace add KardanovIR/agstatus
/plugin install agstatus@agstatus
/agstatus:setup

On macOS the installer also sets up Focus, so a tap on the board brings that session's terminal to the front. It prints what that sends; --no-focus skips it, and --minimal sends tool and folder names instead of command text, prompts and session titles.

Windows PowerShell 5.1 and up. Claude Code and Codex hooks, same as everywhere else; Focus is macOS-only.

Runs inside Claude Code — no terminal needed. Claude Code only; for Codex use the installer.

02

Open the board

The installer prints your private board URL and a QR code — scan it to carry the board on your phone. Made the board in the app first? Pair this machine to it with the short code the app gives you: --code XXXX-XXXX.

03

Get back to work

Sessions appear the moment your agents report in, and update live. Nothing else to configure.

What it sends

A session id, project folder name, a name for the card (that folder, or a Claude session's own title), status word, and a short activity line. Install with --minimal to send tool names and folder names only. Opt into Focus on a machine and it also sends a label for that machine and the name of the app your agent runs in — never a path.

Plan usage stays local

Your Claude and Codex credentials are read on your machine, and token counts come from the logs those tools already keep there. Only percentages, reset times and totals reach the board — never a prompt, a file, or a line of code.

Your data, deletable

Sessions stop being served 24 hours after their last update, and you can delete a board and everything in it at any time. Privacy policy.
