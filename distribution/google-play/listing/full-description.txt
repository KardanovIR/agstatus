AgStatus turns your phone into a live status board for the AI coding agents running on your computer. Kick off a task, walk away from the desk, and check what every session is doing right now: planning, coding, running tests, waiting on you, or finished.

AgStatus is an independent open-source project that plugs into the hook systems of Claude Code and OpenAI Codex. It is not affiliated with, endorsed by, or sponsored by Anthropic or OpenAI.

How it works

A small hook script on your computer posts a short update whenever an agent starts a session, edits a file, runs a command, or gets stuck. Your board server keeps those updates and streams them to the app. One command sets the whole thing up: curl -fsSL https://agstatus.online/install.sh | sh

The app is a companion for a machine where agents run. It reads your board; it does not run agents on the phone.

On the board

- One card per session: the name, the current activity line, and which machine it is running on.
- Six plain statuses - idle, planning, coding, testing, blocked, done - each with its own mark as well as its own colour, so the board reads the same if you cannot tell red from green.
- Sessions from both supported agents land on the same board.
- A streaming connection keeps cards current, with a dot in the toolbar for the connection state.
- Tap a card for its timeline: every status change with a timestamp, newest first.
- Usage bars for plan limit windows, with the share used and when the window resets.
- Tap Focus on a card and the Mac running that session brings its terminal window, tab or pane to the front. If the session has already ended, the card offers Resume instead and the Mac starts it again where it left off.
- Pull to refresh. Swipe a card away once you are done with that session.
- Nothing on the board animates for its own sake. A card moves when it has news, and the system setting for reduced animation is honoured.

Getting connected

Scan the setup QR code your terminal prints, or paste the board URL by hand. To wire up a second machine, the app hands you a short-lived pairing code and the exact command to run. Camera scanning is optional: the camera is used only to read that QR code, the image never leaves the phone, and pasting the URL works just as well.

No account, by design

No sign-up, no email, no password, nothing to subscribe to. A board is an unguessable token in a URL, much like a webhook address. The app keeps that URL in encrypted storage on the device and talks to no server other than the one you point it at. No ads, no analytics, no advertising identifiers, no third-party tracking.

Try it with no server

Demo mode fills the board with sample agents so you can see how it reads. It runs entirely on the phone, with no server and nothing sent anywhere.

Run the whole thing yourself

The server, the web dashboard, the command-line tool, and this app are MIT licensed. Point the app at the hosted instance or at a server you run yourself: a single Node process, with a Docker image and optional PostgreSQL persistence.

What actually leaves your computer

Your machine sends the board a session id, the project folder name, a name for the card (that folder, or a Claude session's own title), one status word, a short activity line, and timestamps. Nothing else. Minimal mode sends only tool names in messages and names every card after its folder, and usage reporting can be switched off too. On the hosted server, sessions stop being shown or served 24 hours after their last update, and boards untouched for 60 days go the same way. You can delete a board and everything on it from Settings, whenever you like.
