AgStatus turns your phone into a live status board for the AI coding agents running on your computer. Kick off a task, walk away from the desk, and check what every session is doing right now: planning, coding, running tests, waiting on you, or finished.

AgStatus is an independent open-source project that plugs into the hook systems of Claude Code and OpenAI Codex. It is not affiliated with, endorsed by, or sponsored by Anthropic or OpenAI.

How it works

A small hook script on your computer posts a short update whenever an agent starts a session, edits a file, runs a command, or gets stuck. Your board server keeps those updates and streams them to the app. One command sets the whole thing up: curl -fsSL https://agstatus.online/install.sh | sh

The app reads your board; it runs no agents on the phone.

On the board

- Sessions grouped by project, the folder each started in, under a label that stays in view as you scroll. Each card's details start with its agent's mark.
- One card per session: its name, what it is doing now, and the machine it runs on.
- Six plain statuses - idle, planning, coding, testing, blocked, done - each with a mark as well as a colour, so the board reads the same if you cannot tell red from green.
- A session's running subagents are rows on its card: what each was asked to do, what it is doing, and its state.
- While a session is blocked, a bar along the bottom names it and its project; press it to bring that card into view, again for the next. TalkBack says when one becomes blocked.
- Tap a card for its subagents and timeline: every status change, timestamped, newest first.
- Usage bars for each agent's plan limit windows, with the share used, when the window resets, and the agent's session count.
- Tap Focus on a card and the Mac running that session brings its terminal to the front; if the session has ended, Resume starts it again where it left off.
- Cards stay current over a streaming connection. Pull to refresh; swipe a card away when you are done.
- Nothing animates for its own sake: a card moves when it has news, and the system's reduced-animation setting is honoured.

Getting connected

Scan the setup QR code your terminal prints, or paste the board URL. To wire up another machine, the app hands you a short-lived pairing code and the command to run. The camera only reads that QR code; the image never leaves the phone.

No account, by design

No sign-up, no email, no password. A board is an unguessable token in a URL, like a webhook address, kept in encrypted storage on the device. The app talks to no server but the one you point it at. No ads, no analytics, no advertising identifiers, no third-party tracking.

Try it with no server

Demo mode fills the board with sample agents, entirely on the phone, sending nothing anywhere.

Run the whole thing yourself

The server, web dashboard, command-line tool and this app are MIT licensed. Use the hosted instance, or run your own server.

What actually leaves your computer

Your machine sends the board a session id, the project folder name, a name for the card (that folder, or a Claude session's own title), which agent it is, one status word, a short activity line, and timestamps, and, for each subagent, its task, status word and activity line. With Focus on, the default on a Mac, it also sends a label for the machine, a random id for it, and the terminal app's name. Minimal mode sends only tool names in messages, names every card after its folder and numbers subagents; usage reporting and Focus can each be switched off. On the hosted server, sessions stop being shown or served 24 hours after their last update, and boards untouched for 60 days go the same way. You can delete a board and everything on it from Settings at any time.
